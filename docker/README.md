# Docker Lab

## Objective

Learn container fundamentals by deploying and maintaining useful services rather than simply collecting applications.

## Questions to Answer for Every Service

1. What problem does this service solve?
2. What container image is being used?
3. Which ports does it expose?
4. Where is persistent data stored?
5. How does DNS resolve the service?
6. How is access controlled?
7. How is it updated?
8. How is it backed up?
9. How would I restore it?
10. How would I troubleshoot it if it stopped working?

## Candidate Services

- Uptime Kuma
- Pi-hole or similar DNS filtering service
- Grafana
- Prometheus
- Nginx Proxy Manager or another reverse proxy
