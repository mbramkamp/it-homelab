# Ubuntu Server Lab

## Objective

Develop practical Linux server administration skills and integrate Linux systems into the homelab.

## Planned System

**Hostname:** `LINUX01`

## Skills to Practice

- SSH administration
- Users and groups
- File ownership and permissions
- Package management
- systemd services
- Logs and `journalctl`
- Network configuration
- Storage/filesystems
- Scheduled tasks
- Basic shell scripting
